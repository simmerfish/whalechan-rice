## hero-originals/ —— AI 生成的原始立绘

三张 **1728×2304** 的原始大图，奶白底（`#F5EADD`），是游戏里 `art/` 那三张透明立绘的**源材料**。

| 文件 | 用途 |
| --- | --- |
| `whalechan-closed.png` | 闭嘴常态（游戏默认态） |
| `whalechan-open.png` | 张嘴接饭（按住空格 / 按住屏幕时的态） |
| `whalechan-happy.png` | 开心（菜单、结算页用） |

生成方式：火山方舟 · 豆包 Seedream，模型 `doubao-seedream-5-0-flash-260915`，
提示词按官方 character-spec 组装，完整提示词存档在 [../art-source/whalechan-prompt.md](../art-source/whalechan-prompt.md)。

> `art-source/` 里也有一份原图，但缩到了 675×900 方便直接看；这里是**全分辨率**原件。

三张按 character-spec 逐条对齐（鲸鳍耳 = 深藏青尖鳍 + 青蓝内缘膜、呆毛圈环、
女仆头饰在发冠上不压额头、两侧蓝蝴蝶结、白花边衣领、藏青胸缎带嵌蓝宝石、
白围裙蓝鲸徽章、藏青腰带金扣、裙摆金星刺绣 + 金蝴蝶结、白过膝袜、藏青玛丽珍鞋）。

**唯一偏离**：要求 chibi 2.5 头身，实际出来约 compact 3.3 头身（判断 3.3 更耐看，没有重画）。

## svg-drafts/ + svg-previews/ —— 手工画的 6 版 SVG

在决定用 AI 出图**之前**，试着手工用 SVG 画鲸鱼娘。
一版一版改，每版都比上一版好，但**上限始终是「扁平贴纸风」**，够不到官方插画那种质感，最后放弃了这条路。

`svg-drafts/chibi-vN.svg` 是源文件，`svg-previews/chibi-vN.png` 是对应的渲染预览（用 `sips` 渲的）。

| 版本 | 画成什么样 | 主要问题 |
| --- | --- | --- |
| v1 | 最初的 Q 版 | 像水母 / 章鱼，**尾鳍被身体整个挡住** |
| v2 | 加了深色描边、明显的大尾鳍、鲸鳍耳、眼高光、腮红、头顶喷水 | 有点意思了，但还是不像鲸鱼娘 |
| v3 | 补上头发 / 呆毛 / 鲸尾 / 女仆装 / 鲸鳍耳 | 白色头饰位置太低**压在额头上**、呈怪异的 V 形；鲸鳍耳画成浅蓝圆钝块；刘海中间有个倒三角 |
| v4 | 大改头饰和侧发 | 白色头饰画得太大，**像兜帽把整张脸盖住**；鳍耳成深色扁椭圆；侧发像直筒 |
| v5 | 收小头饰 | 脸终于露出来、眼睛也可爱了；但白头顶还**是一大块盖住额头**；鳍耳像深色侧向叶片；尾鳍太细像鱼尾 |
| v6 | 头饰收成发冠上的细蕾丝带；鳍耳改成尖鳍 | **刘海终于露出来了**，整体到「可用的 Q 版吉祥物」水准，但仍偏扁平矢量卡通，和官方插画差距明显 |

### 教训

手绘 SVG 能画出的上限就是**扁平矢量**。想接近官方插画质量，要么有真美术，要么用 AI 出图 ——
所以最后转去走 AI 出图那条路（提示词见 [../art-source/whalechan-prompt.md](../art-source/whalechan-prompt.md)）。
