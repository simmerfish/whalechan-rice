# 鲸鱼娘吃大白饭 🐳🍚

一个单文件网页小游戏。**不装任何东西、不联网、不用开服务器**——双击 `index.html` 就能玩。

- 代码：[MIT](LICENSE)
- 角色与立绘：角色「鲸鱼娘 / Whale-chan」设定来自社区项目 [Neko3000/deepseek-whalechan](https://github.com/Neko3000/deepseek-whalechan)，**非商业**使用，详见 [CREDITS.md](CREDITS.md)

---

## 怎么打开

在访达里双击 `index.html`，或者终端里：

```bash
open index.html
```

推荐用 Chrome / Edge / Safari。窗口越大越清晰（会自动等比放大，最多按 2 倍像素渲染）。

手机上也能玩：把这个文件夹传到手机（或用浏览器打开同一个文件），**横屏**、按住屏幕张嘴即可，玩法见下面的「操作」。

## 操作

### 键盘

| 按键 | 作用 |
| --- | --- |
| **按住** 空格 / ↑ / W | **张嘴**——只有张着嘴碰到白饭才能吞下去 |
| **松开** | **闭嘴**——白饭砸在身上会弹开，算「漏接」 |
| ← → 或 A / D | 左右移动（带一点点惯性） |
| Enter | 菜单里确认 |
| ← → | 在**米饭图鉴**里翻页（共 12 种，分 2 页） |
| Esc | 暂停 / 返回上一层 |
| R | 一局里快速重开 |

### 手机 / 平板（触屏）

有触摸屏的设备上，**第一次用手指点屏幕**之后游戏会自动切到触屏操作，画面里会多出几个半透明按钮：

| 操作 | 作用 |
| --- | --- |
| **按住屏幕任意位置** | **张嘴**（不用非得按按钮，最省事） |
| 左下 **◀ ▶** | 左右移动 |
| 右下 **张嘴** 圆键 | 和「按住任意位置」等效，给喜欢按实体按钮的人 |
| 左上方 **⏸** | 暂停 / 继续 |
| 标题页右下 **⛶ 全屏横屏** | 进全屏并尽量锁横屏（iOS Safari 不支持锁定的话，手动把手机横过来就行） |

- **支持多点**：左手拇指推着 ◀ ▶，右手拇指按住屏幕别处张嘴，可以同时生效。
- 菜单、难度选择、图鉴翻页、结算页的按钮都能**直接点**。
- 竖着拿手机会弹出一层「请把手机横过来」的提示，转横屏就消失。
- 本来就没有触摸屏的电脑**不会**显示这些虚拟按钮，界面和以前完全一样；鼠标点击也走同一套热区，所以桌面端用鼠标点菜单同样有效。

## 规则

### 怎么算赢、怎么算输

| | 条件 | 结果 |
| --- | --- | --- |
| ✅ **赢** | 撑到右上角**开饭倒计时归零** | 结算页出现「**吃饱啦！**」，另加 `300 × 难度倍率` 的通关奖励分 |
| ❌ **输** | **饱食度掉到 0** | 饿晕，本局结束 |

- 屏幕最上面那条彩色横条就是**开饭进度**（倒计时走完 = 100%）。
- **饱食度**随时间往下掉；吃白饭回升，吃垃圾暴跌。
- **连击**：连续吃对，每 5 个 +1 倍率，最高 ×5，任何一次失误清零。
- **判定顺序**：先判嘴（椭圆），再判身体（矩形）。
  - 张着嘴碰到食物 → 吞掉
  - 闭着嘴被白饭砸中 → 弹开，算漏接（**不扣饱食度，只断连击**）
  - 闭着嘴被垃圾砸中 → 安全弹开

### 食物

| 图标 | 名字 | 分数 | 饱食度 | 备注 |
| --- | --- | --- | --- | --- |
| 🍚 | 大白饭 | +10 | +6 | 主力食物 |
| ✨ | 黄金大白饭 | +20 | +10 | 严格 2 倍，下落快 20% |

### 正面 buff（6 种）

| 图标 | 名字 | 持续 | 效果 |
| --- | --- | --- | --- |
| 🍙 | 大饭团 | 瞬间 | 立刻回复 **35% 饱食度**，最能救命 |
| 🫧 | 泡泡护盾 | 8 秒 | 惩罚物全部被弹开，这段时间可以放心张嘴 |
| ⭐ | 双倍分数 | 10 秒 | 得分 ×2（跟黄金饭叠起来是 ×4） |
| ⏳ | 细嚼慢咽 | 8 秒 | **全场**下落速度 −40%，慢慢吃 |
| 🧲 | 鲸吞磁力 | 8 秒 | 白饭会被横向吸向嘴巴，站着不动也能吃到 |
| 👑 | 黄金雨 | 10 秒 | 这 10 秒内刷出来的白饭**全部变成黄金饭** |

> 出现概率约 6%，同屏最多 2 个 buff 道具；重复吃同类只**刷新时长**，不叠加。

### 惩罚物

| 图标 | 名字 | 饱食度 | 附加效果 |
| --- | --- | --- | --- |
| 🛍️ | 塑料袋 | −12 | 断连击 + 闭嘴硬直 1.2 秒 |
| 🥫 | 易拉罐 | −16 | 断连击 |
| 🍵 | 伪装芥末饭 | −8 | 断连击 + 屏幕抖动 |
| 🪼 | 水母 | −8 | 断连击 + 画面模糊 2 秒 |

> 得分公式：`基础分 × 连击倍率 × 双倍buff × 难度倍率`

## 三个难度

| | 简单 | 普通 | 困难 |
| --- | --- | --- | --- |
| 初始下落速度 | 120 px/s | 170 px/s | 230 px/s |
| 惩罚物从第几秒开始 | 40s | 25s | 15s |
| 惩罚物占比上限 | 22% | 30% | 38% |
| 饱食度消耗 | −0.9/s | −1.2/s | −1.5/s |
| **通关时长** | **90 秒** | **75 秒** | **60 秒** |
| 分数倍率 | ×0.8 | ×1.0 | ×1.3 |

最高分**按难度分别记录**，存在浏览器的 localStorage 里（键名 `whalechan-rice-v1`）。

## 想改手感？全在这一个地方

打开 `index.html`，搜索 **`调参区`**，所有可调的东西都聚在那里：

```js
var DIFFS = { easy: {...}, normal: {...}, hard: {...} };   // 难度：速度/出怪间隔/惩罚占比/消耗/倍率

var FULLNESS_MAX   = 100;   // 饱食度上限
var FULLNESS_START = 65;    // 开局饱食度（调高=更简单）
var SPEED_RAMP_SEC = 75;    // 多少秒后下落速度加到顶
var SPEED_RAMP_MAX = 0.55;  // 最多加速 55%

var ART_H = 300;            // 鲸鱼娘画多高（逻辑像素）
var GROUND = 556;           // 脚底 y（比 540 大一点=腿被画面裁掉一点，构图更好看）
var SPR_CX = 0.456;         // 立绘里"身体中线"的横向比例
var SPR_MY = 0.272;         // 立绘里"嘴"的纵向比例
var MOUTH_RX = 62, MOUTH_RY = 50;   // 嘴部判定椭圆（想吃得更轻松就调大）
var BODY_HW = 54, BODY_TOP_F = 0.60; // 身体判定框（半宽 / 距地面高度比例）

var MOVE_ACC = 7200, MOVE_DAMP = 9.0, MOVE_MAXV = 820;  // 左右移动手感（嫌慢就调大 ACC / MAXV）
var WIN_BONUS = 300;          // 通关奖励基础分（再乘难度倍率）
var BUFF_CHANCE = 0.06;       // 每次出怪抽到 buff 的概率
var BUFF_ON_FIELD_MAX = 2;    // 同屏最多几个 buff 道具
var SLOW_FACTOR = 0.60;       // 「细嚼慢咽」的全局下落速度倍率

var ITEMS = { rice: {...}, golden: {...}, ... };  // 每件道具的分数、饱食度、半径、速度、效果
```

改完直接刷新浏览器就生效，不用重新构建。

## 开发用脚本

下面这些只是改游戏时用的，**玩的时候完全不需要**。
脚本都按「仓库根 = `whale-game/`」来定位文件，在哪儿执行都一样，推荐：

```bash
cd whale-game

python3 tools/keyout.py 输入.png 输出.png 34     # 抠图（第三个参数是容差，默认 34）
python3 tools/composite.py                      # → preview/halo-check-*.png，检查白边
python3 tools/preview_hitbox.py                 # → preview/check_layout.png / check_states.png
python3 tools/preview_touch.py                  # → preview/check_touch.png
node    tools/harness2.js                       # 回归：界面导航 + 120 秒乱按压力测试
node    tools/harness3.js                       # 回归：通关 / buff / UI 越界 / 触屏交互
```

**不需要 npm install**：Python 那边只用标准库，Node 那边只用自带模块。

## 换立绘

直接替换 `art/` 里那三个 PNG，保持：

1. **背景是透明的**（用 `tools/keyout.py` 从奶白底图抠，或自己用别的方式抠好）
2. **脚底贴着图片下边缘**（游戏是按下边缘对齐地面的）
3. 三张姿态尽量同一个大小，否则张嘴时会有一点缩放跳动

替换后如果发现「嘴的位置不对」，就调 `SPR_MY`（用 `tools/preview_hitbox.py` 边看边调最方便）。
